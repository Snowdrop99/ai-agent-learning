# Agent Loop 笔记（sandbox 里给 agent 读的假资料）

## 循环结构
observe -> think -> act -> observe，直到模型不再请求工具。

## 步数预算
- 简单任务：1-3 步就够。
- 推荐 max_steps = 6。超过 6 步基本说明工具在互相打转，或者任务该拆。
- 一个真实经验：步数上限设太大会把"卡死"伪装成"很努力"，日志里看不出问题。

## 超时
除了总时长预算，单次请求也要设 timeout。两个都要，缺一个都会挂住。

## 错误处理
工具抛异常不要往外扔，转成字符串喂回模型，让它自己纠错。
但要在日志里记下原始异常，否则你在生产环境永远不知道模型在偷偷重试什么。
